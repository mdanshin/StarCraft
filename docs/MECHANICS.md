# Матрица адаптации StarCraft II

«Есть» означает проверяемое правило в `src/engine.js`. «Частично» означает работающую упрощённую модель. «Проект» означает описанный следующий модуль, которого в коде 0.1 ещё нет. Ни один статус не означает полную идентичность конкретному патчу SC2.

| Механика | Карточная реализация | Статус 0.1 | Следующий шаг |
| --- | --- | --- | --- |
| Три асимметричные расы | Разные строительство, восстановление, способности и технология | Есть | Расширить ростеры |
| Минералы / веспен | Два независимых запаса и расходы | Есть | Привязать добычу к месторождениям |
| Обучение рабочих | Цена, очередь базы, потребление лимита | Есть | Рабочие как отдельные юниты |
| Насыщение экономики | 8 минералов и 3 газа за цикл на базу | Частично | Пониженная отдача сверх насыщения |
| Исчерпание ресурсов | 80 минералов и 60 газа на базу | Есть | Разные поля и богатые минералы |
| Перевод рабочих | Приказ распределения общего пула | Частично | Физический маршрут и эвакуация |
| Экспанды | Вторая база, запас ресурсов, дополнительные слоты | Частично | Фиксированные экспансионные узлы |
| Урон экономике | Налёт на рабочих в секторе базы | Частично | Точные рабочие и линии добычи |
| Снабжение и блокировка | Резерв в очереди, потеря поставщика, восстановление | Есть | Полная шкала и точные пакеты |
| Очереди производства | Отдельные производители, таймеры | Есть | Автоповтор и rally points |
| Параллельная тренировка | Несколько зданий / несколько личинок | Есть | Реактор на две очереди |
| Технологические требования | Проверка всех необходимых завершённых зданий | Есть | Полные ветки и исследования |
| Разрушение производства | Потеря связанной очереди без возврата | Есть | Урон и пауза по стадиям |
| Отмена заказа | 75% ресурсов вниз, освобождение лимита | Есть | Отдельные исключения морфов |
| КСМ на стройке | Временно исключён из добычи | Есть | Позиция КСМ и смена строителя |
| Рабочий зерга становится зданием | Уменьшение пула и лимита, возврат при отмене | Есть | Точное здоровье морфа |
| Освобождение зонда | Строительство не занимает добывающего рабочего | Есть | Время пути зонда |
| Ремонт | Ресурсы + свободный рабочий + восстановление HP | Частично | Дальность и автопочинка |
| МУЛ | Энергия преобразуется в минералы | Частично | Временный юнит и орбитальная станция |
| Сканирование | Видимость + обнаружение до конца цикла | Есть | Энергия конкретной станции |
| Подъём и посадка зданий | Двусторонняя карта, смена слоя, отключение очереди | Проект | Модуль T2 |
| Реактор и технический модуль | Сейчас техмодуль — глобальный ключ | Частично | Привязка, обмен, физическое место |
| Планетарная крепость | Альтернативный морф базы с оружием | Проект | Модуль T2 |
| Личинки и инъекция | Личинки базы, отложенная инъекция, естественный предел | Есть | Королева как источник энергии |
| Слизь | Видимая сеть секторов, строительство и скорость | Частично | Опухоли-объекты, распад без источника |
| Закапывание | Состояние без движения/атаки, нуждается в детекции | Есть | Подземное перемещение отдельных типов |
| Регенерация зергов | +1 HP за цикл | Есть | Разные скорости и ограничения |
| Морфы зергов | Преобразование с сохранением ID и разницей стоимости | Проект | Логово/улей, бейнлинг, люркер, выводок |
| Нидус | Связанная сеть входов, транспортная очередь | Проект | Модуль Z2 |
| Питание протоссов | Пилон в секторе/рядом, остановка очереди | Есть | Геометрия и призма |

| Хроноускорение | −1 таймер активной очереди за энергию | Частично | Эффект во времени, конкретный нексус |
| Врата искривления | Заряды производителя, варп в питаемую область | Проект | Модуль P2 |
| Скачок сталкеров | Видимая точка до двух секторов, активация | Есть | Исследование и персональный откат |
| Recall и перегрузка | Отложенная эвакуация / поддержка базы | Проект | Проверка актуального набора способностей |
| Земля и воздух | Разные допустимые цели, обход наземных блоков | Есть | Разные профили оружия по слоям |
| Дальность и минимальная дальность | По рёбрам, ограничение осадного танка | Есть | Несколько колец и дальности зрения |
| Бонусы по атрибутам | Бронетехника, лёгкие, биологические, механические | Частично | Весь набор бонусных профилей |
| Многократные попадания | Отдельная броня на каждом попадании | Проект | Контракт WeaponProfile |
| Перезарядка оружия | Одна активация на цикл | Частично | Таймер по командным окнам |
| Осадный режим | Увеличение дальности/урона, запрет движения | Есть | Отдельная картинка обратной стороны |
| Урон по площади | Вторичные попадания и дружественный огонь | Есть | Линия, конус, разный falloff |
| Псионный шторм | Площадной урон обеим сторонам, без брони | Частично | Высший тамплиер и длительность |
| Стимуляторы | Повторная активация за HP | Частично | Исследование, таймер усиления |
| Высоты | Штраф атаке снизу | Частично | Настоящая линия обзора |
| Узкие проходы и блокировка | Нельзя проходить сквозь врага | Частично | Ширина фронта, force fields |
| Туман войны | Проекция видимых секторов, журнал скрыт | Частично | Серверные проекции и память разведки |
| Детекция | Скан против закопанных целей | Частично | Наблюдатель, надзиратель, ворон, статическая |
| Маскировка | Невидимый, но активный юнит с расходом энергии | Проект | Модуль разведки |
| Иллюзии | Ложная единица, раскрытие детектором | Проект | Сентри и отдельный скрытый тип |
| Башня зел-нага | Расширение обзора при занятии центра | Есть | Оспаривание и радиусы большой карты |
| Разрушаемые камни | Объекты HP открывают рёбра | Проект | Модуль местности |
| Транспорт и дроп | Грузовые слоты, погрузка, разгрузка, гибель груза | Проект | Медивак, призма, надзиратель-транспорт |
| Индивидуальная энергия | Общий пул игрока в учебном режиме | Частично | Источники и регенерация по картам |
| EMP, Feedback, Fungal, Abduct | Контракты источника, окна, цели и ответа | Проект | Полный набор кастеров |
| Временные единицы | Жетоны с таймером и родительским ID | Проект | Локусты, брудинги, перехватчики |

Первичный ориентир по классам состояния — [Blizzard s2client-proto, raw.proto](https://github.com/Blizzard/s2client-proto/blob/master/s2clientprotocol/raw.proto). Протокол содержит признаки полёта, закапывания, маскировки, питания, пассажиров, щитов, энергии и таймеров. Конкретные карточные эффекты в таблице — проектные решения этой адаптации.
